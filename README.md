# Tahoe Studio Pro

A high-performance creative studio operations suite designed for Apple Mac M1 Pro and macOS Tahoe. Manage clients, production crew (CRUD), multi-assignee project timelines, fixed budgets, expenses, deliverables (photobooks, reels, highlights, frames, pendrives), and automated milestone billing reports.

## Quick Start on Mac M1 Pro

```bash
# 1. Install dependencies
npm install

# 2. Start dev server
npm run dev
```

Open `http://localhost:3000` in Safari or Chrome.

## Key Highlights

- **Full Client & Crew Management**: CRUD employee profiles with roles, hourly rates, skills, and availability.
- **Multi-Assignee Projects**: Associate multiple crew members with a single project with custom assigned roles.
- **Fixed Budget & Expense Ledger**: Real-time margin calculations comparing fixed contracted budget limits against logged production expenses.
- **Deliverables Studio**: Dedicated tracking for Photobooks, 9:16 Social Reels, 4K Highlights, Wall Frames, and Engraved USB Vaults with proofing sign-offs.
- **Automated Milestone Billing**: Generate printable/PDF milestone invoices with deliverable verification items and wire details.
- **100% Local Database**: Runs in browser LocalStorage without external cloud dependencies or encryption hurdles. Full JSON backup export and restore.
- **macOS Tahoe Desktop Experience**: Spotlight quick search (`⌘K`), authentic window traffic lights, and frosted glass interface.
